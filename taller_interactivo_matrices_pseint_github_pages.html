1. Conceptos fundamentales

Matriz

Estructura de datos bidimensional organizada en filas y columnas.

Índices

Identifican la posición: matriz[fila,columna].

Ciclos anidados

Un ciclo recorre filas y otro columnas.

Diagonal principal

Elementos cuya fila y columna tienen el mismo índice (i = j).

Diagonal secundaria

En una matriz cuadrada de orden n, cumple i + j = n + 1.

Transpuesta

Se obtiene intercambiando filas por columnas.

Recorrido básico en PSeInt

Para i <- 1 Hasta filas Hacer
    Para j <- 1 Hasta columnas Hacer
        Leer matriz[i,j]
    FinPara
FinPara

3. Reto integrador: sistema de gestión matricial

Una institución educativa necesita administrar las calificaciones de cinco estudiantes en cuatro asignaturas. Los datos se almacenan en una matriz de 5 × 4.

  1. Registrar las calificaciones.
  2. Mostrar la matriz completa.
  3. Calcular el promedio de cada estudiante.
  4. Encontrar la nota más alta y la más baja.
  5. Identificar la posición de la nota más alta.
  6. Contar calificaciones aprobatorias y no aprobatorias (mínimo 3,0).
  7. Mostrar un informe general.
  8. Incorporar un menú que permita repetir operaciones hasta seleccionar «Salir».
